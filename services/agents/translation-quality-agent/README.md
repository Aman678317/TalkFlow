# TalkFlow Agent 05: Translation Quality Agent (QA Agent)

Production-oriented AI Translation Quality Agent in Python for the **TalkFlow / GlobalTalk AI** multilingual communication platform.

## Key Capabilities
- **Independent Quality Evaluation**: Evaluates candidate translations generated by Agent 04 without assuming correctness or fabricating scores.
- **Hard Safety Gating**: Factual errors (number corruption, currency mutation, wrong script, negation flip) enforce an immediate score ceiling $\le 0.35$ and trigger retries or rejection.
- **Ultra-Low Latency (<30 ms)**: Deterministic integrity checks run in $< 10$ ms; reference-free semantic scoring runs in $< 20$ ms.
- **Actionable Decisions**:
  - `ACCEPT`: Dispatched directly to Agent 06 (Voice Generation Agent / TTS) on port 8006.
  - `ACCEPT_WITH_WARNINGS`: Dispatched with telemetry warning notes.
  - `RETRY_WITH_ALTERNATE_PROVIDER`: Feedback sent to Agent 04 with alternative engine recommendation.
  - `HOLD_FOR_HUMAN`: Held in the human review queue.
  - `REJECT`: Suppressed from playback (fail-closed protection).
- **Out-of-Band Operations Brain**: Built with the OpenAI Agents SDK and local Ollama (`qwen3.5:4b`) for drift analysis and diagnostic reporting without blocking audio delivery.
- **Interactive Control Dashboard**: Full-featured dark-mode web console on port 8005 (`http://127.0.0.1:8005`).

## Quick Start

### 1. Run Unit & Integration Tests
```powershell
& "i:\vioces agent\.venv\Scripts\pytest.exe" tests/ -v
```

### 2. Start Agent 05 Service (Port 8005)
```powershell
cd "i:\vioces agent\translation-quality-agent"
& "i:\vioces agent\.venv\Scripts\uvicorn.exe" app.main:app --host 127.0.0.1 --port 8005 --reload
```

### 3. Open Control Dashboard
Visit: `http://127.0.0.1:8005` in your browser.
