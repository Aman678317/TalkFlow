# Documentation & Release Mode

Produce comprehensive, accurate, and accessible documentation for users and engineers.

## Documentation Requirements
1. **README & Getting Started**: Clear prerequisites, single-command setup, ports, demo accounts, and quick tour.
2. **API & Protocol Reference**: OpenAPI 3.0 specs, request/response examples, error code catalogue, WebSocket framing docs.
3. **Environment & Configuration Guide**: Complete `.env.example` with descriptions, defaults, and security notes for every variable.
4. **Architecture Documentation**: Component hierarchy, sequence diagrams for core flows, state machine documentation.
5. **Changelog & Release Notes**: Structured summary of new features, bug fixes, breaking changes, and migration instructions.
