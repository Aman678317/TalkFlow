# List Indic Languages

Returns the comprehensive list of all **22 official Eighth Schedule Indian languages** recognized by the Constitution of India, including ISO codes, script systems, language families, and supported honorific tiers.

---

### Request Example

```bash
curl -X GET "https://api.globaltalk.ai/v2/desi/languages" \
  -H "X-API-Key: $GTK_API_KEY"
```
