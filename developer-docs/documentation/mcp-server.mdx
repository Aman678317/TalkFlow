# Model Context Protocol (MCP) Server

GlobalTalk AI provides a native, clean-room **Model Context Protocol (MCP)** server operating over standard input/output (`stdio`). This allows LLM orchestrators (such as **Claude Code**, **Cursor**, and **VS Code**) to directly execute text translations, cultural honorific adjustments, transliterations, and document operations within developer workflows.

---

## ⚙️ MCP Client Configuration

### Claude Code (`~/.claude.json`)

Add the Desi MCP server to your Claude Code global configuration:

```json
{
  "mcpServers": {
    "desi-mcp": {
      "command": "node",
      "args": ["c:/Users/acer/3D Objects/globaltalk-ai/mcp/desi-mcp-server/dist/index.js"],
      "env": {
        "DESI_API_KEY": "gtk_live_0123456789abcdef",
        "DESI_BASE_URL": "http://127.0.0.1:8088"
      }
    }
  }
}
```

### Cursor (`.cursor/mcp.json`)

```json
{
  "mcpServers": {
    "desi-language-ai": {
      "command": "npx",
      "args": ["-y", "desi-mcp-server"],
      "env": {
        "DESI_API_KEY": "gtk_live_0123456789abcdef"
      }
    }
  }
}
```

## 🔒 Stdio Transport Architectural Rules

### 1. The Zero-Stdout Leakage Rule
When implementing or running stdio MCP servers:
> **`stdout` is strictly reserved for newline-delimited JSON-RPC 2.0 frames.**

Any arbitrary `console.log()` or `print()` to `stdout` corrupts the JSON-RPC framing parser, breaking client execution. In our MCP servers:
- Standard diagnostic logs route strictly to `stderr` (`console.error()` / `sys.stderr.write()`).
- All tool execution frames format cleanly to `stdout`.

### 2. Operational Error Semantics
Linguistic or business errors (such as an unrecognized dialect or rate limit warning) are returned as **informative tool results** with `isError: true` rather than crashing the JSON-RPC transport:

```json
{
  "content": [
    {
      "type": "text",
      "text": "Linguistic Error: 'kashmiri' requires Perso-Arabic or Devanagari script parameter."
    }
  ],
  "isError": true
}
```
This enables the host LLM to inspect the error explanation and self-correct seamlessly.
