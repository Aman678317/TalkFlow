# Contributing to Desi CLI

Thank you for contributing to Desi CLI and GlobalTalk AI.

## Getting Started

```bash
git clone https://github.com/Aman678317/Anv-AI.git
cd globaltalk-ai/cli/desi-cli
npm install
npm run build
npm test
```

## Development Workflow

1. Follow Test-Driven Development (TDD).
2. Write unit tests for new services and commands.
3. Validate format parsers and API clients with mock fixtures.
4. Ensure `npm run lint` and `npm run type-check` pass before submitting PRs.
